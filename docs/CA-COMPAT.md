# جسر ca_api — تشغيل ألعاب مكتوبة لـ CloudArcade على منصتنا

## ما هذا وما ليس هذا

`public/assets/ca-compat.js` كائن `ca_api` يعيد إنتاج **التواقيع المنشورة علناً** في صفحة
توثيق CloudArcade (`submit_score` / `get_current_user` / `get_scoreboard` / أسماء أنماط
اللوحة). هذا عمل **clean-room**: التواقيع وقائع غير محمية، ولم يُقرأ ولا يُنقل أي ملف مصدر
منهم — لا تنسخ `api.js` أو حزمهم النموذجية إلى هذه الحزمة أبداً؛ فمنتجك يُباع حصرياً
ومن غير انتهاك.

## ما يربحه صاحب الموقع

ألعاب HTML5 جاء مطوروها يدمجون `ca_api` (Construct 3 ونحوها) تعمل على منصتك **دون تعديل
ملفاتها**:

| اللعبة تنادي | الجسر يفعل |
|---|---|
| `ca_api.submit_score(1000)` | `POST /api/score` بالرمز الموقّع من صفحتك |
| `ca_api.get_current_user()` | `null` (منصة بلا حسابات — عيّنة كودهم تعالج `null` أصلاً) |
| `ca_api.get_scoreboard({type:'top-week',amount:10})` | `GET /api/leaderboard` ويعيد **نص JSON** كما تتوقع عيّنتهم (`JSON.parse` بأنفسهم) |
| `ca_api.show_ad()` | لا شيء — خانات الإعلانات ملك صفحتك (AdSense) |

والفرق عن منصتهم: عندهم «Game API لا يعمل مع التثبيت في مجلد فرعي» — عندها نقاط النهاية
HTTP حقيقية والجسر يتبع `base`، فلا يوجد هذا القيد.

## التركيب في قالب صفحة اللعبة

```html
<script>
  window.NawrasArcade = {
    game:  '<?= e($game['slug']) ?>',
    token: <?= json_encode($signer->pageToken($game['slug'])) ?>,
    base:  ''            // اتركه فارغاً؛ أو origin آخر إن كانت الـAPI منفصلة
  };
</script>
<script src="/assets/ca-compat.js"></script>
```

قالب PHP مسؤول عن `token` — العميل لا يحسبه ولا يرى السرّ. انتهى.

## الحدود بصدق

النتيجة يرسلها العميل، والرمز صالح لعشر دقائق للزائر نفسه — محدود بـrate-limit (30/دقيقة
موصى به عند التوجيه) وبتوقيع الصفوف المخزّنة. هذا هو السقف الصادق لكل أركيد منفّذ في
المتصفح، ومنافسونا التجاريون بلا استثناء. الفارق أن عندنا: تكرار الإرسال يفشل بصوت مسموع
(403/419/429)، والعبث المباشر بالجدول يكشفه `verifyRow()` عند القراءة.

## ممنوعات الترخيص (تذكير)

- لا تنسخ أو تُعيد تسمية ملفات CloudArcade — الجسر كتبته أنت من التوثيق العام فقط.
- ألعاب موزّعي CloudArcade نفسها بلا إثبات ترخيص في سجلّك ⇒ الـaudit سيخفيها تلقائياً
  (`no_license_row`) — وهذا التصميم الصحيح، لا تلغه.
